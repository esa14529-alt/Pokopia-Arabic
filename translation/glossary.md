# Pokopia Arabic glossary

Keep in Latin script exactly as written (do not translate or transliterate):
- Pokémon species names (Pikachu, Ditto, Machoke, Graveler, Sharpedo, ...)
- Move names (Rain Dance, ...)
- "Pokémon" stays "Pokémon" when it is the bare word; in compounds use the Arabic below.

Style: friendly, simple Modern Standard Arabic suitable for all ages. Short UI labels
stay short (buttons have limited width). Casual Pokémon chatter (Yeah, Whoa, Hehe,
Ummm, Nope, ...) becomes natural Arabic interjections (أجل، واو، هيهي، امم، كلا).
